Beyond the per-member split, three pieces of shared infrastructure shaped the
result. The frozen instruction-set specification
(\texttt{docs/spec.md}) was agreed before any RTL was written, so eight modules
by five authors integrated without a port mismatch. The Python golden model
defined what each instruction must produce independently of the Verilog, which
turned ``the hardware is correct'' into a test result rather than an opinion.
And the random-program fuzzer compared the integrated machine against that model
over thousands of generated programs, finding a reset-time write-enable defect
that all eight hand-written testbenches missed.
